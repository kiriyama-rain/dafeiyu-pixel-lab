# dafeiyu-pixel-lab

把一条鲸鱼娘从「六个版本都不像人」重画成能用的角色图，全过程留档：失败项、提示词全文、可复现脚本、评测表。

- **代码与文档开放，图片不授权**：角色形象是基于他人设定的二创，权利不在我们手里，详见 `NOTICE.md`。
- 想复现：拿自己的角色图跑 `run.py`，别拿这里的图去用。
- 目标不是「我画得好」，是「坏在哪、怎么改、改完用同一把尺子量」。

## 目录

```
prompts/   每一轮提示词全文（原文不加工，含失败版）
results/   生成结果，文件名带轮次与模型
docs/      五条评测尺子的定义与打分表
run.py     复现脚本（读 config.env，key 自己填）
config.env.example
```

## 复现

```
cp config.env.example config.env   # 填 API_KEY / API_BASE
python3 run.py prompts/round3.txt
```

## 评测（五条尺子）

| 项 | 判据 |
|---|---|
| 头身比 | 头高 / 全身高，目标 1:3.5–1:4 |
| 手 | 可见手指数必须 ≤5，且结构连续 |
| 光影 | 光源方向单一，暗部不打架 |
| 像素纯度 | 是否严格对齐到网格，无抗锯齿渐变 |
| 角色相似度 | 与表情包原角色的发色/鳍/围裙结构比对 |
