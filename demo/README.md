# 动起来 demo（9 秒）

结论先说：**刚体傀儡能证明「设定图在画面里立得住」，但证明不了「她会走路」。**

- idle / walk / run / jump / hold 五段，整身做位移、缩放、倾斜，尾巴单独一层摆动。
- 背景和道具是代码画的；角色是 `results/r4-V2.jpg` 抠底后整张贴上去的。
- 没有骨骼、没有分帧——所以走路是平移加起伏，不是迈腿。

**这个 demo 能回答的问题**：配色在深底上够不够亮、角色在 1080p 里该占多高、抠图边缘干不干净、道具挂上去像不像拿着。
**回答不了的问题**：迈腿时裙摆和尾巴怎么动、奔跑的拖影、落地的挤压。

要回答后者只有两条路：拆骨骼做分层傀儡，或者手画 sprite 帧。demo 里的腿是硬的，一眼能看出来。

产物：`demo.mp4`（1920×1080 / 30fps / 9 秒）、`demo-sheet.jpg`（每秒一帧）、`demo.py`（生成脚本，纯 PIL + ffmpeg）。
