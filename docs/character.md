# 角色设定（V2 定稿 · 2026-10-26）

定稿来源：`results/r4-V2.jpg`（参考图 = dsh-meme 表情包 `ganfan.jpg` + 上一版渲染）。
三视图 `results/r5-sheet.jpg`，表情表 `results/r5-face.jpg`，都从这张出发。

## 比例

- 全高约 3 头身（头含头饰约占 1/3）。
- 头宽 ≈ 肩宽 × 1.25；裙摆最宽处 ≈ 头宽 × 1.35。
- 鲸尾从裙摆右侧伸出，尾展 ≈ 全高 × 0.45。

## 不能动的特征（改任何一个就不像她）

1. 深藏青长发，发梢渐浅蓝，长度过腰，发尾卷曲。
2. 头顶一撮呆毛（一个弯钩）。情绪变化时呆毛是主要信号：震惊竖起、难过耷拉。
3. 白色蕾丝女仆头饰，两侧各一个浅蓝蝴蝶结。
4. 藏青色鲸鱼鳍耳朵（不是人耳）。
5. **手是浅蓝色鳍，没有手指、没有指甲、没有肤色**——这条最容易被模型丢掉，每次生成都要重申。
6. 藏青连衣裙 + 白色荷叶边下摆 + 浅蓝小蝴蝶结；白围裙带浅蓝波浪边，围裙上印一条小鲸鱼。
7. 白色及膝袜，藏青圆头鞋。
8. 蓝白鲸尾，从右侧伸出。

## 主色板（从 V2 提取，占比降序）

| 用途 | 色值 |
|---|---|
| 背景白 | `#FFFFFF` |
| 头发暗部 / 裙身 | `#282E5C` |
| 描边 / 最暗 | `#0C1039` |
| 头发中间调 | `#364F8D` |
| 浅蓝（鳍、蝴蝶结、围裙边） | `#7EA1CF` |
| 白布暗部 | `#E3E4ED` |
| 发梢亮部 | `#405994` |

像素化时按这张表量化到 32 色以内，别让模型自己挑色——它会把描边和暗部混成一个色。

## 表情

四套：`happy`（弯眼张嘴）、`shy`（脸红、视线下移、抿嘴）、`shocked`（瞪眼张嘴、呆毛竖起）、`sad`（眼睑下垂、嘴角向下、呆毛耷拉）。见 `results/r5-face.jpg`。

## 生成时的话术（照抄）

- 先给参考图，再说「保持这些不变：脸型眼型、发型发色、头饰、鳍耳、连衣裙、围裙、袜子鞋子、鲸尾」。
- 然后单独一条硬要求：「手是浅蓝鳍，无手指、无肤色」。
- 最后才说风格（平涂、厚描边、无渐变）。
- **别把「简化到 8 色」放在最后一段**——实测它会把手改回人类的手（见 `docs/ref-flow.jpg` 第三格）。
