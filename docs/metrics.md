# 第一批实验结果（2026-10-26）

模型：`banana-2.1`（API 走环境变量，仓库不写渠道）。

## 指标定义

- **颜色数**：整张图不同 RGB 值个数。真像素画应该 ≤ 调色板色数（16/32/8）。
- **网格对齐率**：把图按 N×N 等分，检查每格内是否单一颜色，取最优 N 下的合格格占比。
  真像素 = 1.0；模型「画的像像素」通常在 0.05 上下。
- 检测脚本 `check.py`，可对任意图跑。

## 结果

| 文件 | 路线 | 颜色数 | 网格对齐 | 判定 |
|---|---|---|---|---|
| r1-A1 | A 日系厚涂插画 | 90,946 | 0.025 | 插画，不是像素 |
| r1-A2 | A Q 版扁平 | 53,700 | 0.055 | 插画，不是像素 |
| r2-A3 | A 极简大字块（为像素化准备） | 32,347 | 0.005 | 插画，不是像素 |
| r1-B1 | B 让模型画 64×64 / 16 色 | **30,020** | **0.0455** | **伪像素** |
| r1-B2 | B 让模型画 96×96 / 32 色 | **38,671** | **0.0718** | **伪像素** |
| r1-B3 | B 让模型画 32×32 / 8 色 | 4,749 | 0.0858 | 伪像素（离 8 色差 590 倍） |
| r1-C1 | C 插画直接压 64/16 | 16 | 1.0 | 真像素，但糊 |
| r1-C4 | C 先裁主体再压 64/12 | 12 | 1.0 | 真像素，仍糊 |
| r2-C5 | C 先出「极简大字块」图再压 64/12 | 12 | 1.0 | **真像素，可用** |

## 三条结论

1. **模型不会画像素，只会画「看起来像像素」的画。** 让它画 16 色，它交了 30,020 色；
   边缘是抗锯齿的斜坡，放大 8 倍能看见渐变。人眼在缩略图尺寸下分辨不出来，这是它骗过人的原因。
2. **代码能把任何图变成真像素，但会糊。** 直接降采样会把五官揉掉（C1 / C4）——
   信息量不够，像素只是把损失暴露出来。
3. **先让模型画成「能被像素化」的图，再降采样**（A3 → C5）才成立：
   大色块、粗描边、少细节，降采样后仍然认得出是谁。

## 复现

```
python3 run.py prompts/r2-A3.txt --out results/r2-A3
python3 pixelate.py results/r2-A3.png results/out.png --grid 64 --colors 12 --crop
python3 check.py results/out.png
```
