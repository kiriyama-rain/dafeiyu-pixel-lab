# 已知限制 / 待改善（2026-10-26）

角色资产现状：V2 定稿（`results/r4-V2.jpg`），三视图 `results/r5-sheet.jpg`，表情表 `results/r5-face.jpg`，
像素化验证 `results/r4-V2_px128_32.png`（128 格 / 32 色），刚体 demo `demo/demo.mp4`（9 秒）。

## 1. 走路没做（限制等级：中）

demo 里的 walk 是**整身平移 + 上下起伏 + 轻微倾斜**，腿没有迈开，仔细看就是贴纸在滑。
奔跑同理，只是更快、起伏更大。

**影响**：镜头里不能出现「她走过去」这类需要看清步态的段落，会露馅。

**改善路径**（二选一）：
- 手画 sprite 帧：正面 / 侧面各 6 帧，像素风本来就逐帧，最稳。
- 分层傀儡：把腿、裙摆、鳍手拆层，关节藏在裙下，但平涂图拆不好会露缝。

## 2. 端碗动作不准确（限制等级：高）

demo 里的碗是代码画的，挂在胸前偏右，**没有真的被手握住**：手的位置没变，碗只是叠上去，角度也不对。
用户判定「不太准确」，本轮先不做。

**影响**：不能拍「端着碗吃饭 / 递碗」这类特写。

**改善路径**：
- 先定手部锚点（鳍手尖端的坐标），把碗的握持点固定在那儿，再按上身倾斜做跟随。
- 或者干脆换成「碗放在桌上，她低头看」这类不需要握持的构图。

## 3. 其他未做

- 表情还没接进动画（表情表是静态的，四套脸没做切换）。
- 落地没有挤压回弹（jump 只有上升和下落）。
- 没有转向帧（现在只能左右翻转，侧面是真缺的）。

## 使用边界（写片子前先看这条）

当前资产**能用**的镜头类型：站着说话、轻微浮动、转身、低头抬头、前倾后仰、表情特写。
**别用**的：走路、奔跑、端碗吃饭、需要看清手脚动作的任何段落。
